# Mudi

**Crea la tua pagina web** direttamente nel browser, senza scrivere codice.

Apri `index.html` in un browser qualsiasi (non serve installare niente).

## Come si usa
- **Aggiungi sezione** – menu, copertina, testo, immagine + testo, tre colonne, galleria, citazione, pulsante, contatti, piè di pagina.
- **Modifica** – clicca su un testo per riscriverlo; clicca su un'immagine per cambiarla (URL o file dal computer); doppio clic su un pulsante per cambiarne il collegamento.
- **Organizza** – passa sopra una sezione e usa ↑ ↓ per spostarla, ⧉ per duplicarla, ✕ per eliminarla.
- **Stile** – colore principale, carattere e sfondo chiaro/scuro dal pannello a sinistra.
- **Anteprima / Mobile** – guarda la pagina come la vedranno i visitatori, anche su telefono.
- **Esporta HTML** – scarica la pagina finita in un unico file `.html`, pronto da pubblicare.
- **Salva / Apri progetto** – salva il progetto in un file `.json` per riprenderlo in seguito.

Il lavoro viene salvato automaticamente nel browser.
