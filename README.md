# Green and Clean S.r.l. — sito web

Sito vetrina statico (HTML + CSS, nessuna build) per Green and Clean S.r.l. e CIC Green Cooperativa.

- `index.html` — pagina unica: servizi, prodotti, metodo, dati aziendali, contatti
- `styles.css` — stili responsive
- `assets/img/` — logo e foto tratte dalla presentazione aziendale

Per vederlo basta aprire `index.html` nel browser. Si può pubblicare gratis con GitHub Pages
(Settings → Pages → Deploy from branch) o Netlify.
